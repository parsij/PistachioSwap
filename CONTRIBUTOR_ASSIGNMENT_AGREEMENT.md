## 9. Acceptance and electronic signature

For each pull request, the Contributor must personally check the Contributor Assignment Agreement acceptance box placed in the pull-request description by the repository’s pull-request template. The required statement is:

> I have read and agree to the PistachioSwap Contributor Assignment Agreement Version 1.2. By checking this box from my authenticated GitHub account, I intend this action to serve as my electronic signature. I confirm that I own or control the rights I am assigning, have authority to assign them, and understand that this Agreement covers my applicable existing and future PistachioSwap Contributions as described in the Agreement.

Checking the box containing that statement from the authenticated GitHub account used for the pull request constitutes the Contributor’s acceptance and electronic signature for purposes of this Agreement. The Contributor agrees that the authenticated GitHub account, repository, pull request, commits, checked statement, edit history where available, and timestamp form the electronic record of acceptance.

A maintainer, repository owner, bot, or other person must not check the acceptance box on behalf of the Contributor. If the Contributor does not personally accept the Agreement, the Contribution must not be merged.

A separate public legal-name statement is not required for an individual Contribution. For a Contribution made on behalf of an organization, the person accepting this Agreement represents that they have authority to bind that organization.
